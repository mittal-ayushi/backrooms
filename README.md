# backrooms

Its a small horror exploration game where you wander through the backrooms (inspired by the original backrooms)
 
Demo Link - https://gobackrooms.netlify.app/
 
To run locally - Clone the repo or Download the files and then run `npx serve` or `python -m http.server` then open the localhost link.
Opening index.html directly will not work.

## What It Actually Is
 
When running index.html, you click Enter and land on a start screen. Click anywhere to lock your mouse and step into the Backrooms.
 
Controls -
 
- W/S or Up/Down arrows: walk forward / backward
- A/D, Left/Right arrows, Mouse: turn camera/look around
- Shift: run

Pressing Esc flashes the message:
 
"THERE IS NO ESCAPE TO THE BACKROOMS"

## Stuff I Used
HTML, CSS, JS and three.js for the 3D part.
